AWS · Azure · GCP → OVHcloud · Scaleway · UpCloud

Assess a move to an EU cloud

shift2eu compares an AWS, Azure or GCP inventory with what OVHcloud, Scaleway and UpCloud offer, so you can see how far a move to an EU cloud would go before you plan it. It runs entirely in your browser, and nothing you paste leaves it. shift2eu is provided free to use by Timothy Mamo.

Paste an inventory of your AWS, Azure or GCP resources, choose one or more EU cloud providers, and see what moves directly, what moves with changes and what blocks the move. The assessment runs in this browser: the page sends nothing anywhere.

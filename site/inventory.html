Build an inventory

The assessment reads an inventory: one JSON file that lists your resources. Make it with your provider's own command-line tool, read-only credentials and jq: run the commands below, then the program from the repository that turns their output into inventory.json. Every command lists, describes or queries, and none changes anything in your cloud.

The inventory guide (opens in a new tab) on GitHub is the full text these commands come from: the permissions each provider needs, what each command collects and how the programs classify it.
